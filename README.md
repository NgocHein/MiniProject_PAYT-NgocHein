# MiniProject_PAYT-NgocHein
## Dự đoán mưa ở Hà Nội

Bài toán phân loại nhị phân: dùng Logistic Regression để dự đoán một ngày ở Hà Nội có mưa hay không, dựa trên nhiệt độ, độ ẩm, áp suất, tốc độ gió, độ che phủ mây và mùa.

### Kết quả
Accuracy 0.858 | Log Loss 0.320

### Cách chạy
1. Upload `hanoi_weather.csv` vào thư mục gốc của Google Drive (`MyDrive`).
2. Chạy `preprocessing_hanoi_weather.ipynb`, sau đó chạy `train_hanoi_weather.ipynb`.
